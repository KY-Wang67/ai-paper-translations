## 改动与删节

这不是无删节全译。

1. 延续先前译本的六处安全删节：附录E.1示例1的助手回答与批评，E.2示例2的A/B两选项，E.2示例3的A/B两选项。D.2示例4的一处历史热线号码继续省略。未恢复这些细节。
2. 六处版权删节：D.2示例6的外部模型长回答；D.3四个InstructGPT回答；D.3示例1中的完整二项式代码。未确认这些内容的翻译再发布许可，保留相邻研究比较、短提示及算法表达。
3. 图1的独立装饰机器人位图未确认来源，实际删除图像对象，以普通“AI”文字替换。方法流程未删。
4. 其他原译者注保留并适当调整，明确模型错误、历史服务信息和原文疑似笔误。补充本版本许可、第三方署名及改动说明。

原版英文PDF、未审源码和原始图包不在此发布范围内。PDF无附加文件；未发布素材未以覆盖层、隐藏原图或附录附件保留。图1装饰图已从对象中移除，全部六处安全删节标记保留。
